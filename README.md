# Rain / Route · 城市道路适应暴雨
解压整个目录，在 VS Code 打开 road-lab。R 4.x，仅用 base R 和默认随附软件包；绘图设备需支持 PNG。项目根目录运行：
```r
source("run.R", encoding = "UTF-8")
```
Docker 终端也可使用 `Rscript run.R`。所有分析用英文输出；output/ 为本地计算结果，相同文件名会更新。无需登录或 API key。docs/index.html 是已经组装好的离线网站，直接在 Windows 双击打开即可。用 VS Code 远程连接容器时，如无法双击，本地端口转发 8000 后在工程根运行 `python -m http.server 8000 --directory docs`。GitHub Pages 可选从 main 分支的 /docs 发布。同步前请遵守来源网站的转发要求，已默认忽略下载的第三方原件。
## 数据究竟是什么
- data/sources.csv 汇总资料来源与用途。data/transcribed/closures.csv 是 2026-08-07 北京日报转述北排集团阶段通报中全部七处断路的原始公布字段；道路英文名为翻译。未预填时长、估算客流或补全缺失值。response.csv 保留交通委与北排集团分别报告的时刻及范围；benchmarks.csv 为采购、工程资料和发布方数据的人工转录。初报七条不等同于全市七条；终报十件是集团口径，不能相加。半小时排水、17:20识别险情、17:40断路和17:50通车对应不同定义。110 cm 与 >27 cm 属于不同报道的现场描述，没有逐分钟水位序列。
- 如需归档发布方 HTML/PDF，额外运行 `source("scripts/fetch_originals.R", encoding="UTF-8")`。下载写入 data/raw/，原字节保留。离线计算使用已核对的公布字段。包内没有传感器底层文件、公交 GPS、实际绕行路径、桥区逐时客流、连续多年断路清单或现场工程报价。没有用其他区的雨量冒充桥区雨量。
- config/scenario.csv 的所有数字均为课堂情景设定；滑块上下限是探索范围，不是统计置信区间。350000元是假设的安装总成本。江苏排涝站采购的225836元是单台机组单价，不能代替北京的容量匹配、切换设备及安装报价。北京另一座桥的合同是土建治理，不能当成备用发电投资。北京通勤者调查提供时间价值概念的本地文献，其调查年份和样本不能直接代表本桥乘客。

3. Fig3：假设其余参数相同，随基准年延误改变，三种方案的增量净现值曲线。竖线是默认情景，非观测点；改变配置，重新运行可更新三图与网页默认参数。

## 比较口径
H = 年中断次数 × 每次实际受影响人数 × 人均额外行程分钟 / 60。上述三项均为情景量；真实封路持续时间不能替代人均延误。s 是年度出行延误中与泵站供电中断有关的份额（按人时而非事件个数）；e 是方案对该部分延误的削减比例。按代表年恒定，避免的出行时间 H×s×e。待命方案是提前部署移动抽排或供电，可缩短响应；固定备用电源通过独立供电减少停泵。两者互斥比较，均需保障安全检查。未证明本桥设备容量、停电时排水能力或干预效果。
A = 各年年末折现因子之和；PV收益 = A×H×s×e×每人时价值。PV成本 = 期初建设费 + 高峰施工天数×每日新增延误人时×同一时间价值 + A×新增年维护费。现状各项增量为零。比较采用同一不变价人民币，不设残值；假设投入即生效、期内无需重置，未计伤亡、财产、环境、设备残值或大型改建的多种附带效益。“净收益”限于本模型覆盖的增量社会收益，不是财政利润。静态预算负担可看资本费与维护费。气候情景通过调整事件频率探索，不构成区域降雨趋势预测。
## 展示时怎么用
第1页可用跑马地亲历；第2页用 Fig1 和定位图；第3页用 03a/b；第4页用 Fig2；第5页用 05a/b；第6页用 06a/b；第7页用 Fig3 或网页现场演示；第8页讨论跨部门出资与复核。香港运动场在游乐场地下，不应说成在赛道正下方。所有插图为原创概念图，设施位置与尺寸不按比例。
网页演示：先选择备用供电，降低供电故障占比，观察工程价值下降；改为待命方案，再提高受影响人数，看排序何时改变。图表纵轴均随输入伸缩，比较数值请看表。跨方案比较时保持同一组外部假设。若某路段断路主要来自下游顶托或超容量，两个供电相关选项均不宜直接外推。
## 文件
run.R 为入口；R/model.R 是 R 公式；R/check_model.R 运行零折现手算校验。docs/model.js 实现相同公式供浏览器离线计算，docs/params.js 来源于 config/scenario.csv。assets/ 为可直接插入幻灯片的英文 PNG。中国案例不提供现场投资推荐或实证拟合系数。

附加输出：output/required_effectiveness.csv 给出针对供电中断损失至少要挽回的比例；大于1表示即便完全消除此类延误，单计出行时间仍无法抵回成本。output/context_benchmarks.csv 在 R 内转换公布金额单位；output/input_manifest.csv 存各输入的 MD5，便于核对组员的版本。captions.txt 单列英文图注。
scripts/draw_schematics.py 为七幅概念图的生成源，仅供日后修改；PNG 已随包提供，运行 R 无需 Python。
